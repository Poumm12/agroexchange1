Place these files here for production:

favicon.ico         - 32x32 or 64x64 ICO file (convert favicon.svg)
apple-touch-icon.png - 180x180 PNG for iOS
og-image.png        - 1200x630 PNG for social media previews

To convert favicon.svg to .ico, use:
  https://favicon.io/favicon-converter/
  or: npx @squoosh/cli --mozjpeg '{}' favicon.svg
